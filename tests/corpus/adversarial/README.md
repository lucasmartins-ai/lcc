# Adversarial corpus

Synthetic transcripts (hook shape) that every test run replays through the seven invariants in
[`tests/invariants.py`](../../invariants.py) (`test_invariants_hold_on_the_adversarial_corpus`).
Each file is `{"note", "goal", "payload"}`. No session data: every case is written by hand or
generated by the fuzz test.

To keep a fuzz failure forever, copy the shrunk `failing-<seed>.json` from the nightly
artifact (or from `LCC_FUZZ_ARTIFACTS` locally) here, edit its `note` to say what broke, and
fix the code until the replay passes. Cases named after a bug (`*_rededupe`, `failsafe_*`,
`whitespace_only_*`, `short_stash_*`, `pinned_result_*`) came from the harness's first runs.
