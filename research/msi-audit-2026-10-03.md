## Findings fixed here

1. **False semantic label on a fully protected mechanical pass.** In the merged
   base, provider resolution initialized `semantic_guarantee` to `judged`;
   only a later scoring branch changed it to `none`. With zero pending
   blocks, the branch never ran. The packaged workflow reported three
   protected blocks, zero calls and `judged`. The new regression
   `test_fully_protected_mechanical_pass_does_not_claim_semantic_judgment`
   failed with `judged != none`, then passed after setting the mechanical
   label at provider resolution. Context bytes and selection policy are unchanged.
2. **CI lint and types did not block failures.** Both commands used `|| true`,
   and mypy checked only three files. Full configured-package mypy exposed
   two errors from reusing a raw-dict loop variable for parsed transcript
   messages. Renaming that variable fixes the type conflict without changing
   behavior. CI now runs blocking Ruff and `mypy` over 95 configured files.
3. **Hook tests omitted from CI.** Node CI ran only `test/index.test.js` even
   though `npm test` also runs 11 hook-mapping tests. CI now uses `npm test`.
4. **NOTICE absent from the built wheel's license files.** Packaging declared
   only `LICENSE`. `license-files` now includes `NOTICE`; wheel/sdist checks
   verify both files are present. This preserves existing attribution.
5. **README did not describe current MSI delivery accurately.** The old README
   was 771 lines with repeated installation/usage material, a stale test count,
   no MSI quickstart/status, broad semantic claims and unsourced comparative
   wording. It also showed `lcc explain report.json` after a compact command
   that did not write that report. The replacement creates all inputs/outputs,
   separates preparation/planning/execution, labels benchmarks and points to
   published failures. Provider-window calibration details remain in topic docs.

## Open findings blocking research release

### R1 — sprint-7 costs are final-attempt costs

`benchmarks/msi-bench/bench.py::run_arm` calls `_modeled_cost` once using
final context/model after `run_execution`. Its `frontier_call_modeled` is a
single terminal-model flag. Retried attempts are not included, unlike the
sprint-9 probe harness. The frozen decision-01 verification arm records three
attempts but one cost of 1.072 modeled USD. The aggregate and Pareto are
therefore not full-chain cost comparisons. No replacement figures are
invented here; all-attempt instrumentation, revalidation and an explicit
new evidence revision are needed before promoting those claims.

### R2 — bootstrap is not paired as documented

`bench.py::bootstrap_ci` draws task indices inside its arm loop while advancing
one RNG. Different arms get different samples. Instrumenting `random.Random`
with two resamples confirms that the first two arms' draws differ, contrary
to the docstring/methodology. The present output is marginal per-arm intervals,
not shared-resample paired uncertainty or a test of quality equivalence.
Use the same task draw across arms and revise the evidence transparently.

### R3 — sprint-7 `--check` accepts aggregate drift

`run.py::main(check=True)` verifies the outcome digest and task hashes; it
does not compare all receipt fields, aggregates, uncertainty or Pareto.
A temporary copy with full-context aggregate cost changed to 9999 still
prints `reproducible`. The committed artifact is never modified in the probe.
This limits what a successful `--check` proves. The sprint-9 checker has a
stronger stable-payload contract and tests for receipt/aggregate tampering.

Reproduce R2/R3 without changing frozen results, from the repository root:

```sh
PYTHONPATH=src:benchmarks/msi-bench python - <<'PYPROBE'
import json, random, tempfile
from pathlib import Path
from unittest.mock import patch
import bench
import run
original = random.Random
draws = []
class RecordedRandom(original):
    def choice(self, seq):
        value = super().choice(seq)
        draws.append(value)
        return value
frozen = json.loads(run.RESULTS_PATH.read_text())
with patch('random.Random', RecordedRandom):
    bench.bootstrap_ci(frozen['runs'], resamples=2)
print('shared draws:', draws[:24] == draws[24:48])  # False
frozen['aggregate']['full']['cost_usd_modeled_total'] = 9999
with tempfile.TemporaryDirectory() as directory:
    path = Path(directory) / 'results.json'
    path.write_text(json.dumps(frozen))
    run.RESULTS_PATH = path
    run.main(check=True)  # still accepted
PYPROBE
```

### R4 — evidence is not a production or independent selector evaluation

The sprint-7 and sprint-9 curated `msi` arms use exact required-fact/citation
carrier labels to protect context. That oracle selector is not the public
mechanical compiler. The actual replay tests preservation of pytest summaries
from 10 windows correlated within seven local sessions, not the original
agent objective. Both arms make zero inference calls. The curated probe track
publishes 25/60 terminal failures and all 25 investigations; this must remain
visible beside its successful cells. Live inference quality, billing, latency,
independent holdout data and external transfer remain unmeasured.

These are explicit research limitations, not runtime-test failures. Claims of
novelty, superiority or release readiness require sprint-10 review; this audit
makes none. No frozen dataset, threshold or historical result is silently changed.
