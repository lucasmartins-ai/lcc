## LongHealth v1: a pre-registered study on public clinical records

Until now every lcc number came from the maintainer's own sessions. LongHealth v1 runs `stashed` +
`recall` on LongHealth (20 fictional patients anyone can download), against full context, two
summaries and a verifier loop. The protocol, gates and budget were declared before the pilot, amended
after it, and frozen before any call on the 18-patient set D.

On set D every validity gate passed. One of its 54 sessions was dropped, and scoring that session as
well leaves the verdicts unchanged.

- **H1 passed.** With recall over its stash, the stashed context scored 0.889 on answerable
  questions against 0.887 for full context: +0.1 points, 95% CI −1.9 to +2.1, against a −5 margin.
- **H2 failed.** On exact values it beat a generic summary by 10.8 points, but not a clinical
  summary: +1.4, with a CI that includes 0.
- **The verifier loop cost 8.4 points** of accuracy.

This is one run with one answerer model. Read these numbers as that run's results, not as general
behaviour: the owner's evidence check labels them inferred until a replication exists. Results and limits are in
[`RESULTS.md`](../../benchmarks/research/longhealth-v1/RESULTS.md).

## Added

- **Head stash pointer, opt-in** (`--stash-pointer head`). The pointer carries the first 160
  characters of the removed text, so the model can tell what it would recall. Set D ran with it.
- **`lcc handoff`**: a verbatim, checked packet for the next agent.
- **`lcc recall --file`**: says whether a recalled file read still matches the file.
- **`lcc hint`, opt-in**: a one-line recall hint when a prompt names something stashed.
- **Claude Code plugin**: early auto-compaction is held back when little of the context could be
  stashed.
- **Statusline context fill** and `docs/COMPACT_EARLIER.md`: how to compact earlier in seven
  agent tools.
- **Compaction threshold replay** on real sessions (model estimates, not measurements).
- **`CITATION.cff`**, so the software and the study can be cited.

## Changed

- Intake category model v3 is the default. `LCC_INTAKE_CATEGORY_MODEL=v1` keeps the previous one.

## Fixed

- `recoverable` mode kept a bare first `Output:` line out of the comparison.
- JSONL records holding U+2028 or U+0085 were dropped.
- Codex no longer warns on the plugin's hooks file.
